# 하네스 프루프 (합성 이벤트로 신호·가드의 경계를 증명한다)

sandbox 하네스의 신호(discipline)와 가드(pre 훅)는 **존재가 아니라 경계가 계약**이다 — 언제 발화하고 언제 침묵하는지가 틀리면 벤치 셀을 통째로 날린다(실측: TAIL-TRIM 이 베이스라인 초록 구간에서 오발해 셀 1개가 424초 만에 산출물 0 으로 끝났다). 그래서 신호·가드를 고치면 **합성 프루프를 같이 고치고 돌린다** — `make check-harness-proofs`.

## 위치와 형식
- 프루프는 **레포 자산**이다: `.claude/skills/llm-bench/proofs/<name>.proof.mjs`. 세션 스크래치에 두지 않는다(2026-08-28 이관 — 74 케이스가 세션과 함께 사라질 뻔했다).
- 경로는 이식성 있게 푼다: 대상 모듈은 `import.meta.url` 기준(동적 `import()` + `pathToFileURL`), 픽스처는 `os.tmpdir()` 아래에만 만든다. 절대경로 하드코딩 금지.
- 출력은 한 줄에 `PASS <이름>` / `FAIL <이름>`. 검사는 FAIL 0 과 PASS ≥ 1 을 요구한다(PASS 0 은 "안 돌았다"로 본다).
- GPU·서버·네트워크를 쓰지 않는다. 시간은 `Date.now` 를 대체해 합성한다.

## 무엇을 증명하나
- **발화**: 조건이 맞을 때 정확히 한 번 나간다(중복 금지, 세션 상한 준수).
- **침묵**: 건강한 셀은 메시지를 한 개도 안 받는다 — 특히 작업 시작 전(베이스라인이 공허하게 초록인 구간)과 정상 종료 직후.
- **해제·재무장**: 실제 변이/게이트 실행이 윈도를 죽이고 다시 무장시킨다.
- **가드 경계**: 파괴적 편집은 막고(형제 치환·import 교체·등록 줄 소실), 정당한 편집은 통과(값 수정·단일 식별자·삽입형·의도 선언 `# intent: replace`). 읽을 수 없는 경로는 **fail-open**(훅은 절대 던지지 않는다 — omp 는 훅 예외를 도구 실패로 승격시킨다).

## 고칠 때
1. 신호·가드를 고친다 → 2. 프루프에 케이스를 **추가**한다(기존 케이스를 지우지 않는다. 기대가 바뀌면 이유를 주석으로) → 3. `make check-harness-proofs` → 4. 실전 첫 발화를 훅로그로 부검한다.
