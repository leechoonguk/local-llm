# Makefile Usage Rules


## Self-Documenting Targets

Every target carries a `## <description>` on its header line. `make help` greps
those descriptions, so a target without one exists but cannot be found - and an
undiscoverable target is re-invented as a raw command. `check-makefiles`
enforces it on the root, backend, frontend and decks Makefiles.

## Makefile Targets

| Target | Command | Purpose |
|---|---|---|
| `make help` | `grep -E 'target:.*?## .*'` | Show this help |
| `make install` | `uv sync` | Install Python dependencies |
| `make dev` | `start.sh` | Migrate + uvicorn :18000 (reload mode) |
| `make migrate` | `alembic upgrade head` | Apply pending migrations |
| `make migrate-down` | `alembic downgrade -1` | Roll back the most recent migration |
| `make migrate-gen` | `alembic revision --autogenerate` | Auto-generate migration from model changes |
| `make verify` | `lint + typecheck + test` | Full quality gate (fail-fast) |
| `make verify-fast` | `lint + typecheck + test-fast` | Iteration gate — no coverage; the finish still requires `make verify` |
| `make test-fast` | `pytest -q --no-cov $(t)` | Tests without the coverage gate; `t="tests/..."` scopes to one file |
| `make down` | `lsof -ti:18000` + `xargs kill -9` | Stop backend (kill uvicorn) |
| `make test` | `pytest -q` | Run tests (100% coverage gate) |
| `make lint` | `ruff check app alembic tests` | Lint Python code (incl. tests) |
| `make fix` | `ruff check --fix` + `ruff format` (app tests — alembic 제외) | Auto-fix lint findings and formatting; migrations are immutable artifacts |
| `make typecheck` | `pyright` | Type-check Python code (incl. tests) |
| `make clean` | `rm -rf .coverage .pytest_cache .ruff_cache __pycache__` | Remove test, lint, coverage, and Python caches |

## Usage Conventions

1. **All targets run from `backend/` directory.** `make dev` starts from `backend/`.
   No target strips the environment: `Settings` declares `.env` as the winning
   source (`settings_customise_sources` in `settings.py`), so an exported
   variable cannot outrank the file for *any* entry point — make target, bare
   `uvicorn`, pytest in an editor, or CI. The 16-key strip list this Makefile
   used to carry was the same contract written a fourth time.
2. **Verify before commit.** `make verify` (lint + typecheck + test) must pass.
3. **Roll back before re-migrating.** If a migration is broken: `make migrate-down`, fix, `make migrate`.
4. **`migrate-gen` requires `m=` message.** `make migrate-gen m="add foo table"`.
5. **Run `make migrate` after `migrate-gen`.** Autogenerated migration must be applied.
6. **Run `make migrate-down && make migrate`** after applying a new migration to verify reversibility.
7. **Stop backend with `make down`.** Use before restarting to avoid port conflicts.
