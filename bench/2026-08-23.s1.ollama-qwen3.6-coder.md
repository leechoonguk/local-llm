## 과제
`/api/chat` 단발 프롬프트 → 코드 블록 추출 → 실행 테스트(exit code)로 채점. 4과제:

| id | 과제 | 채점 |
|---|---|---|
| t1 | Python `LRUTTL` 클래스(LRU 축출 + put 기준 TTL, 만료는 `__len__` 제외) | pytest 류 실행 |
| t2 | 겹치거나 맞닿은 닫힌 구간 병합 함수의 버그 수정 | 실행 |
| t3 | nginx combined 로그 stdin → 줄당 JSON, 표준 라이브러리만 | 셸 |
| t4 | Node CommonJS `debounce(fn, wait, {leading, trailing})` + `.cancel()` | node |
