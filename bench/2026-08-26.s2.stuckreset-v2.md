## 판단 (n=2)
- **v2 = 1/2 초록·회귀 0 — baseline(1/2 초록·회귀 0)과 정확히 동률.** 개선 증거도, 악화 증거도 없다. "좋으면 표준"이라는 채택 기준에는 못 미친다 — **표준 baking 보류**, 확장은 옵트인 실험 자산으로 유지.
- **메커니즘 자체는 검증됐다(이 실험의 실질 수확).** 컨텍스트를 4회 통째로 리셋(최대 133개 메시지→5개)해도 네이티브 todo + 중립 nudge 만으로 모델이 흐름을 잃지 않고 게이트 초록까지 완주할 수 있다(#1). "컨텍스트 = 소모품, todo = 지속 기억" 릴레이 아키텍처가 로컬 3.6 에서 성립한다.
- **주기 리셋은 무해하나 개선도 아님** — 4회 리셋이 완주를 막지 않았지만(#1), 실패 셀(#2)의 미완성 1 도 못 막았다. REST 의 ~50% near-miss 는 여전히 모델 능력 천장.
- **동일성 기반 반복 감지는 이 모델에 무용** — 3.6 은 같은 것을 3번 똑같이 반복하지 않는다(변형 헤맴). 잡으려면 유사도/의미 신호가 필요하나, 도메인 하드코딩 배제 원칙과 긴장 관계 — 후속 판단 필요.
- 이전 실패 재확인: 강제 지속(discipline)·저온(temp 0.3)이 유발하던 env.py 회귀가 v2 에선 없음(회귀 0).
